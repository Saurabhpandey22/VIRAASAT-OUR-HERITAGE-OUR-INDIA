# Viraasat 🇮🇳 — Our Heritage, Our India

**Viraasat** is a web application dedicated to celebrating and preserving India's 
rich cultural heritage — its history, traditions, art, monuments, and diversity — 
built using Google AI Studio.

🔗 **Live Demo:** https://viraasat-our-heritage-our-india.onrender.com/

## 📖 About the Project

India's cultural legacy spans thousands of years, yet much of it remains 
scattered and inaccessible in one place. **Viraasat** aims to bring this 
heritage closer to people through an interactive, AI-powered platform that 
showcases India's traditions, historical sites, art forms, and stories — 
making cultural learning engaging and accessible for everyone.

## ✨ Features

- 🏛️ Explore India's rich heritage, culture, and traditions
- 🤖 AI-powered features for an interactive experience
- 📱 Responsive, user-friendly interface
- 🌐 Deployed and accessible online
